# 🏏 Virat Kohli – The King of Cricket

## 📌 About the Project

This project is a tribute website dedicated to **Virat Kohli**, one of the most celebrated cricketers in modern cricket. It highlights his inspiring journey, personal life, cricket career, major achievements, records and contributions to Indian cricket.

The website is developed as part of my **Web Development & Designing Internship**.

## 🎯 Objectives

- Create an attractive and responsive tribute webpage.
- Showcase Virat Kohli's biography and personal life.
- Highlight his major cricket achievements.
- Present his career journey through a timeline.
- Share inspirational quotes.

## 🛠️ Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layouts, colours and responsive design.

## ✨ Features

- Attractive navigation bar.
- Hero section with Virat Kohli's photograph.
- Biography and personal life sections.
- Major achievements and career highlights.
- Career timeline.
- Inspirational quote section.
- Responsive design for desktop and mobile devices.
- Footer with reference links.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure the images folder contains the required photograph.
4. Open `index.html` in your web browser.
5. Explore the different sections of the website.
